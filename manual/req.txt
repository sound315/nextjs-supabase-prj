1단계: 커스텀 커맨드, 훅, 서브에이전트 설정하기
이전 시간에 배운 내용을 참고하여 개발 생산성을 높이는 도구들을 설정합니다.

설정할 항목:

커스텀 커맨드: 자주 사용하는 명령어를 단축키로 등록
훅(Hooks): 특정 시점에 자동으로 실행되는 작업 설정
서브에이전트: 반복 작업을 자동화하는 에이전트 설정
강의에서 배운 방법대로 각 도구를 프로젝트에 적용하고 테스트하세요.

--

2단계: 유용한 MCP Server 설정하기
AI 개발 도구를 프로젝트에 연동합니다.

설정할 MCP Server:

프로젝트에 유용한 MCP Server 선택 및 설치
설정 파일 작성 및 연동 테스트
AI와의 협업 환경 구축
강의 내용을 참고하여 프로젝트에 적합한 MCP Server를 설정하세요.

--

3단계: 프로젝트 문서 생성하기
프로젝트 루트에 docs 폴더를 생성하고 핵심 문서를 작성합니다.

생성할 문서:

docs/PRD.md: 프로젝트 요구사항 문서

프로젝트 개요 (목적과 목표)
핵심 기능 목록
기술 스택
사용자 스토리
docs/ROADMAP.md: 개발 로드맵

Phase 1: MVP 개발 계획
Phase 2: 기능 확장 계획
각 단계별 체크리스트

--

4단계: CLAUDE.md 초기화 및 컨텍스트 설정하기
AI가 프로젝트를 더 잘 이해하도록 컨텍스트 파일을 구성합니다.

설정할 내용:

CLAUDE.md 생성: 프로젝트의 메인 컨텍스트 파일
프로젝트 개요
폴더 구조
주요 규칙 및 컨벤션
기술 스택별 컨텍스트 파일 생성 (예시):
docs/next-js.md: Next.js 관련 규칙
docs/supabase.md: Supabase 사용 가이드
docs/coding-style.md: 코딩 스타일 가이드
CLAUDE.md에서 컨텍스트 파일 import:
@docs/next-js.md
@docs/supabase.md
@docs/coding-style.md
이렇게 구성하면 AI가 필요한 컨텍스트를 자동으로 참조할 수 있습니다.
