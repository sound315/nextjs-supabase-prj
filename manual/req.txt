1단계: 탐색 및 정보 수집하기
구현하려는 기능에 대한 정보를 다양한 방법으로 수집합니다.

수집 방법:

docs/ 문서: 프로젝트 내 문서 파일(PRD.md, ROADMAP.md 등)에서 요구사항 확인
이미지 첨부: 참고할 UI 디자인이나 플로우차트를 이미지로 업로드하여 AI와 공유
웹 검색: 유사한 기능의 구현 사례 조사
Supabase MCP: Supabase 문서 및 베스트 프랙티스 확인
Context7: Next.js, React 등 사용 중인 라이브러리 문서 참조
기존 코드베이스: 프로젝트의 현재 구조와 패턴 파악
수집할 정보:

구현하려는 기능의 기술적 요구사항
필요한 Supabase 테이블 구조
UI/UX 참고 사례 및 디자인
예상되는 기술적 난관과 해결책

--

2단계: 작업 계획 생성하기
수집한 정보를 바탕으로 구체적인 작업 계획을 세웁니다.

계획 방법:

방법 1: Claude Task Master AI 활용

복잡한 작업을 자동으로 분석하고 단계별로 분해
작업 간 의존성을 파악하여 최적의 실행 순서 제안
방법 2: Shrimp Task Manager 활용

체계적인 작업 계획 수립 및 관리
각 작업의 우선순위와 상태를 추적
방법 3: Plan Mode 활용

복잡한 기능을 시각적으로 분해하고 단계별 계획 수립
구현 전략과 기술 스택 결정
방법 4: Subagent 활용

특정 문서 생성 작업 위임 (예: ROADMAP.md 생성 및 업데이트)
데이터베이스 스키마 설계 등 전문적인 영역 계획
문서화:

docs/ROADMAP.md 생성 또는 업데이트
필요시 docs/PRD.md에 상세 요구사항 추가
작업 계획을 체크리스트 형태로 정리

--

3단계: 기능 구현하기
계획한 작업을 실제로 구현합니다.

구현 방법:

방법 1: Task Manager 기반 구현

Shrimp Task Manager에서 생성한 작업 목록을 하나씩 실행
각 작업의 완료 상태를 체크하며 진행
방법 2: Subagent 활용 구현

복잡한 컴포넌트나 기능을 서브에이전트에게 위임
백엔드 API, 프론트엔드 UI 등을 병렬로 개발
방법 3: 커스텀 커맨드 및 훅 활용

반복 작업은 커스텀 커맨드로 자동화
특정 시점에 필요한 작업은 훅으로 자동 실행
구현 순서:

Supabase 테이블 생성 및 RLS(Row Level Security) 설정
백엔드 API 로직 구현
프론트엔드 UI 컴포넌트 개발
Supabase 연동 및 데이터 흐름 구현
스타일링 및 UX 개선
중요: 한 번에 모든 것을 구현하지 말고, Task Manager의 작업 단위대로 점진적으로 완성하세요.

--

4단계: 검증 및 커밋하기
구현한 기능을 검증하고 저장소에 반영합니다.

검증 방법:

방법 1: 수동 테스트

브라우저에서 기능이 정상 작동하는지 확인
다양한 시나리오로 테스트
방법 2: Playwright MCP 활용 (선택사항)

자동화된 사용자 플로우 테스트
반복적인 테스트 시나리오 자동화
방법 3: Supabase 대시보드 확인

데이터베이스에 데이터가 올바르게 저장되는지 확인
RLS 정책이 제대로 작동하는지 검증
